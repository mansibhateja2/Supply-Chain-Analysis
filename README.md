# Supply Chain Analysis | Power BI Project

## Project Overview
This project focuses on analyzing supply chain operations using Power BI. The objective is to understand sales performance, customer behavior, order management, delivery performance, and product distribution.

## Tools & Technologies
- Power BI
- Power Query
- DAX
- Data Visualization
- Data Cleaning

## Dashboards Created
1. Overall Supply Chain Overview
2. Sales and Product Analysis
3. Customer Analysis
4. Shipping and Delivery Analysis
5. Market and Regional Analysis

## Key Objectives
- Analyze overall sales performance.
- Understand customer purchasing patterns.
- Evaluate shipping and delivery performance.
- Identify product and market trends.
- Generate meaningful business insights.

## Dataset
DataCo Supply Chain Dataset.
